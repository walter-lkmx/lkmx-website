## Contexto

Negu ofrece ancho de banda y conectividad premium para superyates, cruceros y aviones privados, proporcionando la conectividad más rápida y confiable, con conexiones de baja latencia.

## Desafío

El reto consistió en diseñar y construir un sitio web estático limpio y fácil de mantener, sin un CMS, que representara fielmente la identidad de Negu. 

## Solución

Logic Kernel diseñó y construyó un sitio web de carga rápida, con una apariencia muy limpia y moderna que enfatiza las ofertas del cliente.

![](/work/negu-figure-1.jpg)

## Impacto

Con la nueva presencia digital, el cliente pudo expandir su negocio sin depender exclusivamente del contacto persona a persona.

![](/work/negu-figure-2.jpg)

## Conclusión

Este proyecto demuestra el compromiso de Logic Kernel con sus proyectos; sin importar cuán simples parezcan, se aplica el mismo esfuerzo y se entregan resultados igualmente excelentes.
